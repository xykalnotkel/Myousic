# Myousic untuk Redmi A2 (APK)

WebView yang membungkus https://myousic.vercel.app.

HP Android Go / MIUI (Redmi A2) **tidak support widget** dan sering gagal pasang PWA.
Penggantinya: **notifikasi pemutar** (prev / play / next) + **pintasan layar utama**.

**APK jadi:** `android/Myousic.apk` (v1.3).

## Pasang di HP

1. Hapus Myousic lama kalau sudah terpasang.
2. Buka `Myousic.apk` → izinkan **Install unknown apps**.
3. Buka app. Kalau muncul “abaikan hemat baterai” → **Izinkan**.
4. Kalau muncul “tambah ke layar utama” → **Tambahkan** (ini pintasan, bukan widget).
5. Settings → Apps → Myousic → **Autostart ON**, Battery → **No restrictions**.
6. Kontrol lagu: geser notifikasi turun — ada tombol sebelumnya / jeda / berikutnya.

Jangan *Force stop* kalau mau tetap bunyi.
